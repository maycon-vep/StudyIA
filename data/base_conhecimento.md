# Base de Conhecimento

## Python

Python é uma linguagem de programação interpretada, simples e de alto nível.

Principais conceitos:

- Variáveis
- Tipos de dados
- Listas
- Tuplas
- Dicionários
- Funções
- Estruturas de repetição
- Estruturas condicionais
- Classes
- Objetos

## SQL

SQL é a linguagem utilizada para manipulação de bancos de dados relacionais.

Principais comandos:

SELECT

INSERT

UPDATE

DELETE

WHERE

GROUP BY

ORDER BY

JOIN

HAVING

Exemplos:

Aprendizado de Máquina

Processamento de Linguagem Natural

Visão Computacional

Redes Neurais

Modelos Generativos
