# Perguntas Frequentes

Pergunta:
O que é Python?

Resposta:
Python é uma linguagem de programação de alto nível utilizada em diversas áreas da computação.


Pergunta:
O que faz o comando SELECT?

Resposta:
Seleciona dados existentes em uma tabela.


Pergunta:
O que é uma chave primária?

Resposta:
É um campo responsável por identificar exclusivamente cada registro de uma tabela.


Pergunta:
O que é JOIN?

Resposta:
É utilizado para relacionar informações entre duas ou mais tabelas.


Pergunta:
O que é Inteligência Artificial?

Resposta:
É uma área da computação que desenvolve sistemas capazes de aprender, interpretar informações e tomar decisões com base em dados.
