# Pitch do Projeto

## Problema

Muitos estudantes iniciantes encontram dificuldades para compreender conceitos básicos de programação e acabam consultando diversas fontes diferentes, que podem apresentar informações incorretas ou confusas.

## Solução

O StudyIA é um assistente virtual desenvolvido para responder dúvidas sobre programação utilizando uma base de conhecimento previamente organizada.

Ele responde apenas quando possui informações confiáveis e informa ao usuário quando não é capaz de responder determinada pergunta.

## Diferencial

- Evita respostas inventadas.
- Linguagem simples.
- Fácil utilização.
- Baseado em Engenharia de Prompt.
- Pode ser expandido para novos conteúdos.

## Público-Alvo

- Estudantes
- Iniciantes em programação
- Participantes de bootcamps
- Alunos da DIO

## Tecnologias

- Python
- Inteligência Artificial
- Markdown
- GitHub

## Próximos Passos

- Interface Web
- Banco Vetorial
- Busca Semântica
- Upload de PDFs
- Histórico de Conversas


## Conclusão

O StudyIA demonstra como a Inteligência Artificial pode auxiliar estudantes no aprendizado de programação de forma segura, organizada e baseada em conhecimento validado.
