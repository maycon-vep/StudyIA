# StudyIA - Assistente Virtual com Inteligência Artificial

## Sobre o Projeto

O StudyIA é um assistente virtual desenvolvido para auxiliar estudantes iniciantes de programação. Seu objetivo é responder dúvidas relacionadas a Python, SQL e Banco de Dados utilizando uma base de conhecimento previamente definida, evitando respostas inventadas e fornecendo informações claras e objetivas.

Este projeto foi desenvolvido como solução para o desafio **"Construa Seu Assistente Virtual com Inteligência Artificial"** da Digital Innovation One (DIO).

## Objetivos

- Auxiliar estudantes iniciantes.
- Utilizar Inteligência Artificial de forma responsável.
- Responder apenas utilizando uma base de conhecimento.
- Informar quando não possuir informações suficientes.
- Demonstrar conceitos de Engenharia de Prompt.

## Como Executar

Clone o repositório

git clone https://github.com/seuusuario/assistente-virtual-ia.git

Entre na pasta

cd assistente-virtual-ia

Instale as dependências

pip install -r requirements.txt

Execute

python app.py
